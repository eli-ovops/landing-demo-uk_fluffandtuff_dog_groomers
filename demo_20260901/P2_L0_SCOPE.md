# P2 L0 build scope

## Deliverable boundary

The later build will be a self-contained static local preview. Its folder may contain only `index.html`, `styles.css`, an optional minimal `script.js`, and locally ledgered raster assets. No package installation, framework, database, form handler, analytics SDK, tracking pixel, CMS, or server process is permitted.

## Interaction boundary

- Navigation and booking CTA are ordinary outbound links to a freshly rechecked third-party destination.
- No animated Hero Engine: static photography is the deliberate engine selection for `MOTION_INTENSITY = 2`; therefore no automatic motion is planned.
- The visual must remain fully understandable with JavaScript disabled and with `prefers-reduced-motion` enabled.

## Acceptance to attempt after implementation

- 1440×900 and 390×844 browser checks.
- Each client-visible business claim maps to the business-fidelity map.
- Each image maps to the image ledger, with no customer asset rendered before source/hash/rights registration.
- No internal, rights, AI, draft, authorisation, or package language is visible to the client.
