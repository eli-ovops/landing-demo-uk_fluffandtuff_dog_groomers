# P1 Visual reference map

**Opened and assessed:** 2026-09-01. These are live UK-market references for principles only; no copy, code, imagery, structure, claims, or wording is reused.

| Reference | One useful principle | Intended application | Deliberate non-copy boundary |
| --- | --- | --- | --- |
| [Pawsome Visits](https://www.pawsome-visits.co.uk/) | Make the 1-to-1, home-visit/service proposition visible before the first scroll. | Hero subline makes Fluffandtuff's verified home-based, one-to-one proposition legible. | No home-visit wording, palette, layout, or assets copied. |
| [The Dog Pod](https://www.thedogpodltd.co.uk/) | A calm service hierarchy can lead to a clear external booking action. | Service slice precedes the booking CTA. | No section order, illustrations, copy, or booking UI copied. |
| [Signature Canines](https://www.signaturecanines.co.uk/) | Premium pet-care pages use restraint and readable detail, rather than crowded decoration. | Large editorial type, limited accent colour, and short factual statements. | No luxury/mobile-service claims, imagery, marks, or composition copied. |
| [Artful Dog Grooming](https://www.artfuldoggrooming.co.uk/) | Gallery rhythm can show care and craft without becoming a catalogue. | Four distinct visual beats across the page, each tied to a factual section. | No gallery grid, assets, text, or brand styling copied. |

The selected direction is intentionally not a groomer-template clone: it uses a left-led editorial hero, an offset service rail, a vertical proof panel, and a quiet location-and-external-booking closing block rather than the common centered Hero + three equal cards + testimonial carousel pattern.
