# P0 Scope — Fluffandtuff local concept demo

**Date:** 2026-09-01  
**Owner:** local Demo production owner  
**Stage:** pre-code; customer-visible implementation is not yet authorised by this document.

## Outcome

Create one finished, local-only static concept page for **Fluffandtuff Dog Groomers** in Welling. It must make the verified home-based, one-to-one grooming offer easier to understand and route visitors to the business's existing external booking service.

## In scope

- Static HTML, CSS, and only small progressive-enhancement JavaScript if later needed.
- A client-showable desktop and ~390px mobile page after the Pre-code and later visual QA gates pass.
- Verified business identity, Welling location, selected currently listed services, and external booking links.
- Customer-specific official social identity asset, plus clearly internal-ledgered original concept photography only where official usable imagery is insufficient.

## Explicit exclusions

- Deployment, public hosting, Cloudflare upload, a public URL, email, contact, form submission, payment, booking integration, analytics, tracking, source transfer, or customer-account access.
- An hours grid, prices, review count/rating, credential claim, or service catalogue composed by blending Fresha and SumUp: their current listings conflict.
- Claims that a generated concept image is Fluffandtuff work, premises, staff, customer, dog, or result.
